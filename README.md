# Aplicação de Gherkin em Cenários de Teste

## Sobre o projeto

Este repositório apresenta exercícios práticos desenvolvidos durante meus estudos em QA, com foco na aplicação de Gherkin para elaboração de cenários de teste.

O objetivo é praticar a descrição de comportamentos de uma aplicação de forma clara, estruturada e compreensível para diferentes profissionais envolvidos no desenvolvimento e na qualidade de software.

## Cenários abordados

Neste projeto foram desenvolvidos cenários relacionados a diferentes etapas de uma aplicação:

* Cadastro de usuário
* Login
* Configuração de produto
* Finalização de compra

## Metodologia

Os cenários foram escritos utilizando a estrutura do Gherkin, com a organização:

* `Feature`
* `Scenario`
* `Given`
* `When`
* `Then`

A proposta é transformar requisitos e comportamentos esperados em cenários de teste estruturados.

## Objetivo de aprendizado

Este projeto faz parte da minha trajetória de aprendizado em Quality Assurance (QA), colocando em prática conceitos estudados sobre especificação de cenários e comportamento esperado do sistema.
